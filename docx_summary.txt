Screen 05 — AI Roadmap Generator

Use the established StudyFlow design system from Screens 01–04.

TECH STACK:

Next.js, TypeScript, Tailwind CSS, shadcn/ui, Lucide React, Framer Motion. Use mock/local state only.

PHASE 1:

UI only. Do not implement authentication, Supabase, backend APIs, AI APIs, RAG, or Flutter.

STYLE:

Premium natural glassmorphism. Warm off-white #F6F5F1, white/glass surfaces, #171717 text, #6B6B65 muted text, #E5E3DC borders, forest green #1F6B4F accent, #E7F0EB light accent, #B7791F warning, #B94A48 error.

- Duration

- Preferred learning methods: Theory / Practice / Projects / Coding / Quizzes / Revision

- Generate Roadmap button

RIGHT — live preview:

Show a clean roadmap tree preview with editable-looking topic nodes.

Generation state:

Show a calm sequential process:

Understanding goal → Identifying prerequisites → Structuring topics → Creating practice checkpoints → Preparing roadmap.

After generation, show:

- Generated roadmap title

- Topic count

- Estimated duration

- Interactive preview

- Regenerate

- Edit

Use Framer Motion for subtle transitions. Do not use futuristic AI animations or sparkle effects.
